# Typography

Fixel Text everywhere (`font-sans`). Each `text-*` class sets the font size and its line height together. Prefer the Heading, Text, Eyebrow and Caption primitives, which pick the size and tone for you.

`text-body` is a font size; `text-text-primary` is a color.
